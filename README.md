# PC Futbol Remake ⚽🎮

Juego de gestión de fútbol inspirado en el clásico PC Fútbol 7, remasterizado.

[![Estado del Deploy](https://img.shields.io/github/deployments/mapiedra/pcfutbol-remake/production?label=vercel&logo=vercel)](https://pcfutbol-remake.vercel.app)
[![GitHub issues](https://img.shields.io/github/issues/mapiedra/pcfutbol-remake)](https://github.com/mapiedra/pcfutbol-remake/issues)
[![Licencia](https://img.shields.io/github/license/mapiedra/pcfutbol-remake)](./LICENSE.md)

**Juega ahora sin instalar: [pcfutbol-remake.vercel.app](https://pcfutbol-remake.vercel.app)**

## 🚀 Empezar en 2 Minutos

```bash
# 1. Clonar el repositorio
git clone https://github.com/mapiedra/pcfutbol-remake.git
cd pcfutbol-remake

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```
Ahora, abre [http://localhost:3000](http://localhost:3000) en tu navegador.

### 📱 Desarrollo Android

¿Quieres trabajar con la versión Android? Consulta nuestra [Guía de Capacitor](CAPACITOR.md).

```bash
# Build del proyecto web
npm run build

# Sincronizar con Capacitor
npx cap sync

# Abrir en Android Studio
npx cap open android
```

## ✨ Características

-   **Interfaz Moderna**: Inspirada en el clásico, pero con un diseño limpio y actual.
-   **PWA Instalable**: Instala el juego en tu escritorio o móvil para acceso sin conexión.
-   **App Nativa Android**: Build nativa para Android con Capacitor (ver [CAPACITOR.md](CAPACITOR.md)).
-   **Rendimiento**: Construido con Vanilla JS para ser extremadamente ligero y rápido.
-   **Código Abierto**: Totalmente transparente, auditable y abierto a contribuciones.
